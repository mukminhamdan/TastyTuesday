TUTORIAL STEP BY STEP

Edit video guna Claude
pakai phone 📱

Claude Code (cloud) boleh transcribe, potong, dan cadangkan animasi untuk video kau — semua dari app Claude di telefon. Tak perlu laptop.

✅ App ClaudeDownload dari App Store / Play Store & log masuk.
✅ App GitHubUntuk buat repo tempat Claude simpan kerja.
✅ Google DriveTempat upload video mentah.
5 LANGKAH
1
LANGKAH 1/5

Pilih environment & repo

  • Buka app Claude → menu → Code → New session.
  • Tekan Default → pilih Cloud environment: Default.
  • Tekan Add repository untuk sambung repo GitHub.
2
LANGKAH 2/5

Buat repo GitHub

  • Buka app GitHub → + → New Repository.
  • Beri nama (cth. Video-Claudee), set Private, on Add README → Create.
  • Balik ke Claude → Add repository → pilih repo baru tadi.
3
LANGKAH 3/5

Ambil link Google Drive

  • Upload video ke satu folder dalam Google Drive.
  • Folder → Manage access → General access: Anyone with the link.
  • Copy link folder tu.
⚠️ Kenapa Drive? Upload terus dalam Claude dihadkan 30 MB — video biasanya lebih besar.
4
LANGKAH 4/5

Paste link & prompt

  • Paste link Drive dalam kotak chat, kemudian tulis prompt (bawah).
  • Tukar effort model dari Low ke High untuk hasil lebih teliti.
5
LANGKAH 5/5

Submit & biar dia jalan

  • Tekan butang hantar ↑. Bila Claude minta kebenaran run command, pilih Always allow for this session.
  • Claude akan transcribe & proses — anggaran 20–25 minit. Boleh tutup app.
  • Semak preview dulu, baru minta render final.
